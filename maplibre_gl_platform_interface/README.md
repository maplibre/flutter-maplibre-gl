# maplibre_gl_platform_interface

The interface shared by the platform packages of [`maplibre_gl`](https://pub.dev/packages/maplibre_gl).

Apps depend on `maplibre_gl` and get this package with it. Depend on it directly only to write a platform package, or a fake `MapLibrePlatform` for tests: see [Tests and platform packages](https://maplibre.org/flutter-maplibre-gl/migration/#tests-and-platform-packages).
