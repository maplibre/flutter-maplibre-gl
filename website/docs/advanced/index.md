# Advanced

Everything beyond drawing data on a map: how tiles reach the device, how to
style from data rather than constants, and what to tune when a map-heavy app
feels slow.

- [PMTiles](pmtiles.md): serve map tiles from a single portable file
- [Offline Regions](offline-regions.md): download tiles for offline use (Android & iOS)
- [Map Language](map-language.md): switch map label language at runtime
- [Snapshot](snapshot.md): capture a static image of the map
- [Data-Driven Expressions](expressions.md): style features from their own data
- [Globe, Terrain and Sky](globe-terrain-sky.md): the projection, terrain, sky and light style root objects
- [Feature State](feature-state.md): restyle single features without touching the source
- [User Location](user-location.md): show the puck, or drive it from your own fixes
- [Startup & Performance](performance.md): pre-warming, pausing off-screen maps, large data
