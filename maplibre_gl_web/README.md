# maplibre_gl_web

The web implementation of [`maplibre_gl`](https://pub.dev/packages/maplibre_gl), built on [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js).

Apps depend on `maplibre_gl` and get this package with it. Start from the [documentation](https://maplibre.org/flutter-maplibre-gl/).
